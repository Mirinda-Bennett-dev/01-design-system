# Mirinda's Design System
> **🚀 [Live Demo](https://01-design-system.vercel.app)**

A living library of reusable UI components built with **React**, **TypeScript**, and **Vite**.
This project demonstrates design-token architecture, theming, and clean component API design.

## Features

- Design tokens for color, spacing, and typography
- Light and dark theme with a live toggle
- Reusable components: Button, Card, Input, Badge
- Accessible focus states and semantic markup

## Components

| Component   | Purpose                       |
| ----------- | ----------------------------- |
| Button      | Primary and secondary actions |
| Card        | Content containers            |
| Input       | Labeled form fields           |
| Badge       | Status indicators             |
| ThemeToggle | Light/dark theme switch       |

## Run Locally

    npm install
    npm run dev
